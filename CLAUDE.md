# CLAUDE.md — NoWayOS/.github

The NoWayOS organisation's public profile on GitHub: `profile/README.md` is what visitors see at
github.com/NoWayOS. **Everything here is public.**

- The copy is taken word for word from www.nowayos.com (the home page, the projects and the site's
  facts) and follows that repository's `CLAUDE.md`: its claims discipline, its brand rules and its
  "nothing private" rule. Change the website first, then this page to match.
- `SECURITY.md` is the default security policy for every repository without its own. Keep its
  reporting route the same as theirs, and add no response times until security oversight has
  approved them.
- Images are referenced by absolute `raw.githubusercontent.com` URLs, which resolve only while this
  repository is public. The wordmarks are the brand kit's light and dark PNGs.
- Before every commit, check every file against the workspace's pre-publication term lists, as the
  website's `npm run terms` does (Adappt, the sponsor, is allowed). Commit locally, never push.
